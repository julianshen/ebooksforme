關於本書

本書採用故事驅動的教學方式。主角林小語（25 歲，後端工程師，熱愛咖啡與程式碼）將帶領你從零開始，一步步掌握 LangGraph 的核心原理與實戰技巧。

每個技術概念都會透過小語的視角呈現：

  • 🎭 漫畫插圖：用日式漫畫風格解釋抽象概念
  • 💬 小語的碎碎念：詼諧易懂的口語化解說
  • 🔍 原始碼深度解析：帶你讀懂 LangGraph 的每一行核心程式碼
  • 🛠️ 實務演練：從簡單的聊天機器人到複雜的多 Agent 系統
