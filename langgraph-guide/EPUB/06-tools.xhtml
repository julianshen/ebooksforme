第 6 章：ToolNode 與工具呼叫

「裝備升級！」——小語

6.1 ToolNode 是什麼？

ToolNode 是 LangGraph 預建的工具執行節點。它負責：

  • 解析 LLM 的 tool_calls
  • 並行執行多個工具
  • 處理工具錯誤
  • 回傳 ToolMessage

6.2 ToolNode 原始碼解析

# langgraph/prebuilt/tool_node.py（簡化版）

class ToolNode:
    def __init__(self, tools: list[BaseTool]):
        self.tools_by_name = {t.name: t for t in tools}
    
    def invoke(self, state):
        # 1. 從最後一條 AI 訊息提取 tool_calls
        ai_message = state["messages"][-1]
        tool_calls = ai_message.tool_calls
        
        # 2. 並行執行所有工具
        tool_messages = []
        for call in tool_calls:
            tool = self.tools_by_name[call["name"]]
            result = tool.invoke(call["args"])
            tool_messages.append(
                ToolMessage(content=result, tool_call_id=call["id"])
            )
        
        # 3. 回傳更新
        return {"messages": tool_messages}

6.3 tools_condition 路由

tools_condition 自動判斷 LLM 是否想呼叫工具：

from langgraph.prebuilt import tools_condition

# 自動路由：有 tool_calls 就去 tools，沒有就結束
