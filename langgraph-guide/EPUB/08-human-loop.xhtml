第 8 章：Human-in-the-Loop

「與人類並肩作戰！」——小語

8.1 為什麼需要人類介入？

有些決策 AI 不該獨自做：

  • 💰 涉及金錢的交易
  • 🔒 敏感資料存取
  • ⚠️ 高風險操作
  • ❓ 不確定時需要確認

8.2 Interrupt 機制

LangGraph 內建 interrupt() 函數：

from langgraph.types import interrupt

def sensitive_operation(state):
    # 暫停執行，等待人類確認
    user_response = interrupt({
        "action": "delete_database",
        "risk": "HIGH",
        "question": "確定要刪除資料庫嗎？"
    })
    
    if user_response == "yes":
        return {"result": "deleted"}
    else:
        return {"result": "cancelled"}

8.3 interrupt_before / interrupt_after

在 compile 時設定中斷點：

app = graph.compile(
    interrupt_before=["sensitive_node"],  # 執行前暫停
    interrupt_after=["review_node"]       # 執行後暫停
)

# 執行到 interrupt 會暫停
result = app.invoke(state, config)
# 這裡 result 會顯示中斷資訊

# 人類確認後繼續
result = app.invoke(None, config)  # None = 從中斷點繼續

💬 小語的感嘆

「這就像遊戲的『暫停選單』！AI 做到關鍵步驟會自動暫停，等人類確認後再繼續。安全又彈性！」

8.4 本章總結

  • ✅ interrupt() 在 Node 內暫停等待人類輸入
  • ✅ interrupt_before/after 在 compile 時設定中斷點
  • ✅ 從中斷點繼續：invoke(None, config)
  • ✅ 適合高風險操作和需要確認的場景
