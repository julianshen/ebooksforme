第 5 章：Checkpoint 與持久化

「時間回溯的超能力！」——小語

5.1 什麼是 Checkpoint？

Checkpoint 是 LangGraph 的存檔點。每個 Superstep 結束後，Pregel 可以選擇「存檔」——把當前所有 Channel 的狀態保存起來。

一句話理解：Checkpoint = 遊戲存檔。當機了？讀檔繼續！

5.2 Checkpoint 結構

# langgraph/checkpoint/base.py

class Checkpoint(TypedDict):
    v: int                    # 版本號
    id: str                   # UUID
    ts: str                   # 時間戳
    channel_values: dict      # 所有 Channel 的值
    channel_versions: dict    # 每個 Channel 的版本
    versions_seen: dict       # Node 看到的版本

5.2.1 建立 Checkpoint

# langgraph/pregel/_checkpoint.py

def create_checkpoint(
    checkpoint: Checkpoint,
    channels: Mapping[str, BaseChannel],
    step: int,
) -> Checkpoint:
    """從當前 Channel 狀態建立新的 Checkpoint。"""
    ts = datetime.now(timezone.utc).isoformat()
    
    # 對每個 Channel 執行 checkpoint()
    channel_values = {
        k: v.checkpoint() for k, v in channels.items()
    }
    
    return Checkpoint(
        v=LATEST_VERSION,
        id=str(uuid6()),
        ts=ts,
        channel_values=channel_values,
        channel_versions={...},
        versions_seen={...},
    )

5.3 CheckpointSaver

CheckpointSaver 是持久化介面，支援多種後端：

Saver儲存位置用途
MemorySaver記憶體開發測試
SqliteSaverSQLite 檔案單機持久化
PostgresSaverPostgreSQL生產環境
RedisSaverRedis高速快取
from langgraph.checkpoint.memory import MemorySaver

# 建立 Saver
memory = MemorySaver()

# 編譯圖時綁定
app = graph.compile(checkpointer=memory)

# 執行（自動存檔）
config = {"configurable": {"thread_id": "user-123"}}
result = app.invoke({"question": "Hello?"}, config)

# 取得歷史
history = list(memory.get(config))
for checkpoint in history:
    print(f"Step {checkpoint['step']}: {checkpoint['state']}")

💬 小語的興奮

「這就像遊戲的存檔系統！我可以隨時讀取之前的狀態，甚至『時間回溯』到任意步驟！」

5.4 時間旅行（Time Travel）

LangGraph 支援從任意 Checkpoint 恢復執行：

# 取得所有 Checkpoint
states = list(app.get_state_history(config))

# 回到第 3 步
past_state = states[3]

# 從這裡繼續執行
result = app.invoke(None, past_state.config)

5.5 本章總結

  • ✅ Checkpoint 是每個 Superstep 的「存檔點」
  • ✅ CheckpointSaver 支援記憶體/SQLite/PostgreSQL/Redis
  • ✅ 時間旅行：可以從任意歷史點恢復執行
  • ✅ 生產環境建議使用 PostgreSQL 或 Redis Saver
