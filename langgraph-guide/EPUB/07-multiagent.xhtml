第 7 章：Multi-Agent 系統

「組建冒險小隊！」——小語

7.1 為什麼需要多 Agent？

單一 Agent 面對複雜任務時容易「幻覺」或「分心」。多 Agent 系統讓每個 Agent 專注一件事：

模式說明適用場景
Supervisor一個主管分配任務給多個 Worker任務分類與分派
Network所有 Agent 互相連接，任意通訊開放式協作
Hierarchical層級結構，上級指揮下級企業流程
Plan-and-Execute先規劃再執行複雜多步驟任務

7.2 Supervisor 模式實作

from langgraph.graph import StateGraph, START, END
from typing import TypedDict, Annotated
from operator import add

class TeamState(TypedDict):
    messages: Annotated[list, add_messages]
    next: str  # 下一個執行的 Agent

# Worker Agents
def researcher(state):
    return {"messages": ["Research result: ..."], "next": "supervisor"}

def coder(state):
    return {"messages": ["Code result: ..."], "next": "supervisor"}

# Supervisor：決定誰來做
def supervisor(state):
    # LLM 判斷任務類型
    task_type = classify_task(state["messages"][-1])
    if task_type == "research":
        return {"next": "researcher"}
    else:
        return {"next": "coder"}

# 建圖
graph = StateGraph(TeamState)
graph.add_node("supervisor", supervisor)
graph.add_node("researcher", researcher)
graph.add_node("coder", coder)
graph.add_edge(START, "supervisor")
graph.add_conditional_edges("supervisor", lambda s: s["next"])
graph.add_edge("researcher", "supervisor")
graph.add_edge("coder", "supervisor")

app = graph.compile()

7.3 本章總結

  • ✅ Multi-Agent 讓每個 Agent 專注一件事
