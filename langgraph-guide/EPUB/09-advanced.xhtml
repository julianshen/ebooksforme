第 9 章：進階模式與技巧

9.1 Streaming（串流輸出）

即時看到 Agent 的思考過程：

# 串流每個 Node 的輸出
for event in app.stream(state, config, stream_mode="updates"):
    print(f"Node {event['node']} updated: {event['data']}")

# 串流 Token 級輸出
for chunk in app.stream(state, config, stream_mode="messages"):
    print(chunk.content, end="")

9.3 動態圖結構

在執行時動態添加 Node：

from langgraph.types import Send

# 動態產生多個並行任務
def map_reduce(state):
    items = state["items"]
    # 為每個 item 產生一個並行任務
    return [Send("processor", {"item": item}) for item in items]

graph.add_conditional_edges("start", map_reduce)

9.4 本章總結

  • ✅ Streaming 即時觀察 Agent 執行過程
  • ✅ RetryPolicy 自動重試失敗的 Node
  • ✅ Send 動態產生並行任務
