第 2 章：StateGraph 核心

「StateGraph……這名字聽起來很厲害，但到底是什麼？」——小語

2.1 StateGraph 是什麼？

StateGraph 是 LangGraph 的核心類別。它負責：

  • 定義 State 的結構（Schema）
  • 註冊 Node（節點）
  • 連接 Edge（邊）
  • 編譯成可執行的 Pregel 圖

2.1.1 原始碼位置

StateGraph 定義在 langgraph/graph/state.py，核心類別繼承關係：

# langgraph/graph/state.py
class StateGraph:
    """A graph that operates on a state object."""
    
    def __init__(self, state_schema):
        self.schema = state_schema
        self.nodes = {}
        self.edges = []
        self.branches = {}
    
    def add_node(self, name, action):
        self.nodes[name] = action
    
    def add_edge(self, start, end):
        self.edges.append((start, end))
    
    def compile(self):
        # 編譯成 Pregel 執行引擎
        return Pregel(...)

💬 小語的理解

「所以 StateGraph 就像一個『藍圖設計師』，負責畫好整張圖的設計圖。真正動工的是 Pregel 這個『包工頭』。」

2.2 State 的定義方式

LangGraph 支援多種方式定義 State：

2.2.1 TypedDict（推薦入門）

from typing import TypedDict, Annotated
from langgraph.graph import add_messages

class ChatState(TypedDict):
    messages: Annotated[list, add_messages]
    count: int

2.2.2 Pydantic BaseModel（推薦生產環境）

from pydantic import BaseModel

class ChatState(BaseModel):
    messages: list = []
    count: int = 0

2.2.3 Dataclass

from dataclasses import dataclass, field

@dataclass
class ChatState:
    messages: list = field(default_factory=list)
    count: int = 0

小語建議：初學用 TypedDict，生產環境用 Pydantic。Pydantic 會自動做型別驗證，防止 State 被亂改。

2.3 Annotated 與 Reducer

這是 LangGraph 最強大的設計之一！Annotated[type, reducer] 讓你控制如何合併更新。

2.3.1 預設行為：覆蓋

class State(TypedDict):
    name: str  # 預設：後寫入的覆蓋先寫入的

# Node A 回傳 {"name": "Alice"}
# Node B 回傳 {"name": "Bob"}
# 最終 State.name = "Bob"（B 覆蓋 A）

2.3.2 自訂 Reducer：累加

from typing import Annotated
from operator import add

class State(TypedDict):
    scores: Annotated[list, add]  # 用 add 合併

# Node A 回傳 {"scores": [1, 2]}
# Node B 回傳 {"scores": [3, 4]}
# 最終 State.scores = [1, 2, 3, 4]（合併而非覆蓋）

2.3.3 內建 Reducer：add_messages

from langgraph.graph import add_messages

class ChatState(TypedDict):
    messages: Annotated[list, add_messages]
    # add_messages 會聰明地合併訊息列表
    # 相同 ID 的訊息會被更新而非重複添加

「Reducer 就像收納盒：有的東西直接蓋上去，有的東西要疊在一起！」

2.4 原始碼深度解析：StateGraph.compile()

讓我們看看 compile() 到底做了什麼：

# langgraph/graph/state.py（簡化版）

def compile(self, checkpointer=None, store=None, interrupt_before=None, interrupt_after=None):
    """Compile the state graph into a Pregel application."""
    
    # 1. 驗證圖結構（沒有孤立的節點等）
    self.validate()
    
    # 2. 建立 Channel 對應每個 State 欄位
    channels = self._create_channels()
    
    # 3. 包裝每個 Node 成 PregelNode
    nodes = {}
    for name, action in self.nodes.items():
        nodes[name] = PregelNode(
            action=action,
            channels=channels,
            triggers=[...],  # 哪些 Channel 變化會觸發此 Node
        )
    
    # 4. 建立 Pregel 執行引擎
    return Pregel(
        nodes=nodes,
        channels=channels,
        edges=self.edges,
        checkpointer=checkpointer,
        interrupt_before=interrupt_before,
        interrupt_after=interrupt_after,
    )

重點：compile() 不是「編譯成機器碼」，而是「把設計圖轉換成可執行的執行計畫」。所有 Node 都被包裝成 PregelNode，所有 State 欄位都對應到 Channel。

2.5 條件分支進階

2.5.1 簡單條件

def router(state):
    if state["score"] > 0.8:
        return "excellent"
    elif state["score"] > 0.5:
        return "good"
    else:
        return "bad"

graph.add_conditional_edges(
    "judge",
    router,
    {
        "excellent": "celebrate",
        "good": "continue",
        "bad": "retry"
    }
)

2.5.2 並行分支

def parallel_router(state):
    # 回傳列表 = 同時執行多個分支！
    return ["branch_a", "branch_b", "branch_c"]

graph.add_conditional_edges(
    "start",
    parallel_router,
    {
        "branch_a": "node_a",
        "branch_b": "node_b", 
        "branch_c": "node_c"
    }
)
# 三個分支會同時執行！

💬 小語的驚嘆

「哇！回傳列表就能並行？這比寫 async.gather 還直覺！LangGraph 自動幫我處理並行和同步。」

2.6 子圖（Subgraph）

當圖變大時，可以用子圖模組化：

# 定義子圖
def create_search_subgraph():
    subgraph = StateGraph(SearchState)
    subgraph.add_node("search", search_node)
    subgraph.add_node("summarize", summarize_node)
    subgraph.add_edge(START, "search")
    subgraph.add_edge("search", "summarize")
    subgraph.add_edge("summarize", END)
    return subgraph.compile()

# 在主圖中使用
main_graph = StateGraph(MainState)
main_graph.add_node("search", create_search_subgraph())  # 子圖當作一個 Node！
main_graph.add_edge(START, "search")

2.7 本章總結

  • ✅ StateGraph 是 LangGraph 的核心「藍圖設計師」
  • ✅ State 可用 TypedDict、Pydantic、Dataclass 定義
  • ✅ Annotated + Reducer 控制更新合併行為
  • ✅ compile() 將設計圖轉換為 Pregel 執行引擎
  • ✅ 條件邊支援分支和並行執行
  • ✅ 子圖讓大圖模組化
