第 3 章：意大利開局——經典之美

「這是最古老的開局之一，」貝絲說，「簡單、優雅、充滿可能性。」

老傑克點頭：「意大利開局就像一件剪裁完美的黑色洋裝——永不過時。」

3.1 基本走法與圖解

意大利開局（Italian Game）是西洋棋歷史上最古老的開局之一，早在 15 世紀就被義大利棋手系統化研究。它的核心思想簡單而優雅：控制中心、快速出子、瞄準 f7 弱點。

🎯 為什麼選擇意大利開局？

  • 簡單易學，適合初學者
  • 自然發展子力
  • 控制中心並瞄準 f7
  • 提供多種戰略選擇

第一步：1. e4

白方挺進王前兵，控制中心並為后與象打開線路。

第二步：1... e5

黑方對稱回應，同樣控制中心。

第三步：2. Nf3

白方出動王翼馬，攻擊 e5 兵並控制中心。

第四步：2... Nc6

黑方出動后翼馬，保護 e5 兵並發展子力。

第五步：3. Bc4

白方出動象到 c4，這是意大利開局的關鍵一步！象瞄準 f7 格——黑方最薄弱的點，因為 f7 只有國王保護。

第六步：3... Bc5

黑方也發展象到 c5，控制中心並準備短易位。這是最自然的應對，形成「古典變例」。

完整序列

1. e4 e5 2. Nf3 Nc6 3. Bc4 Bc5

3.2 黑方的主要應對

3.2.1 古典變例：3...Bc5

如上圖所示，這是最自然的應對。接下來常見的續招：

4. c3 Nf6 5. d4 exd4 6. cxd4 Bb4+ 7. Nc3 Nxe4 8. O-O Bxc3 9. d5 Bf6 10. Re1 Ne7 11. Rxe4 d6

這是著名的「莫勒攻擊」（Möller Attack），雙方都有複雜的戰術機會。

3.2.2 雙馬防禦：3...Nf6

黑方立即攻擊 e4 兵，要求白方做出選擇。

白方有兩個主要選擇：

  • 4. Ng5：騎士進攻變例，攻擊 f7 並製造戰術
  • 4. d3：穩健發展，保持中心壓力

3.2.3 匈牙利防禦：3...Be7

較為保守的選擇，黑方避免立即對抗，準備穩固陣型後再反擊。

3.3 貝絲的最愛：伊凡斯棄兵

貝絲特別喜歡一個激進的變例——伊凡斯棄兵（Evans Gambit）：

1. e4 e5 2. Nf3 Nc6 3. Bc4 Bc5 4. b4

白方犧牲一個兵來換取快速的出子和中心控制。這個開局在 19 世紀非常流行，許多偉大的棋手都曾使用。

【漫畫：貝絲在比賽中走出 4.b4，對手驚訝地睜大眼睛】

「棄兵？」對手皺眉。

貝絲微笑：「有時候，你必須先給予，才能得到更多。」

3.4 本章練習

請在棋盤上練習以下意大利開局變例：

  1. 古典變例：1. e4 e5 2. Nf3 Nc6 3. Bc4 Bc5 4. c3 Nf6 5. d3
  2. 雙馬防禦：1. e4 e5 2. Nf3 Nc6 3. Bc4 Nf6 4. d3 Be7 5. O-O
  3. 伊凡斯棄兵：1. e4 e5 2. Nf3 Nc6 3. Bc4 Bc5 4. b4 Bxb4 5. c3 Ba5
