第 7 章：安全性 —— 訊息的護盾

【漫畫：小風發現未授權的訊息】

「有人偷看我們的訂單！」小風驚呼。

「別慌，」陳老師冷靜地說，「NATS 有多層安全機制。讓我們築起護盾。」

7.1 認證機制

7.1.1 密碼認證

// 伺服器設定
authorization {
    users: [
        {user: "admin", password: "secret123"}
        {user: "app", password: "app123"}
    ]
}

// 客戶端連線
nc, _ := nats.Connect("nats://localhost:4222",
    nats.UserInfo("app", "app123"),
)

7.1.2 Token 認證

// 伺服器設定
authorization {token: "mysecrettoken"}

// 客戶端連線
nc, _ := nats.Connect("nats://localhost:4222",
    nats.Token("mysecrettoken"),
)

7.1.3 NKey 與 JWT

// 使用 Ed25519 金鑰對
nc, _ := nats.Connect("nats://localhost:4222",
    nats.UserCredentials("/path/to/user.creds"),
)

7.2 授權（Authorization）

7.2.1 主題級授權

authorization {
    users: [
        {
            user: "order-service"
            password: "order123"
            permissions: {
                publish: ["orders.*", "payments.validate"]
                subscribe: ["orders.*", "inventory.check"]
            }
        },
        {
            user: "analytics-service"
            password: "analytics123"
            permissions: {
                publish: []
                subscribe: ["orders.>", "user.*.events"]
            }
        }
    ]
}

7.3 TLS 加密

7.3.1 單向 TLS

// 伺服器設定
tls {
    cert_file: "/etc/nats/server-cert.pem"
    key_file: "/etc/nats/server-key.pem"
}

// 客戶端連線
nc, _ := nats.Connect("tls://localhost:4222",
    nats.RootCAs("/path/to/ca.pem"),
)

7.3.2 雙向 TLS（mTLS）

// 伺服器設定
tls {
    cert_file: "/etc/nats/server-cert.pem"
    key_file: "/etc/nats/server-key.pem"
    ca_file: "/etc/nats/ca.pem"
    verify: true
    verify_and_map: true
}

7.4 帳戶隔離（Accounts）

Accounts 提供多租戶隔離，不同帳戶的訊息完全隔離：

accounts {
    APP: {
        users: [{user: "app", password: "app123"}]
        exports: [
            {service: "orders.api"}
            {stream: "orders.events"}
        ]
    }
    ANALYTICS: {
        users: [{user: "analytics", password: "analytics123"}]
        imports: [
            {service: {account: "APP", subject: "orders.api"}, to: "external.orders.api"}
            {stream: {account: "APP", subject: "orders.events"}, to: "external.orders.events"}
        ]
    }
}

7.5 實戰：安全設定範例

// 生產環境完整安全設定
port: 4222

authorization {
    users: [
        {
            user: "service"
            password: "$2a$11$..."  // bcrypt 雜湊
            permissions: {
                publish: {
                    allow: ["service.>", "health.check"]
                    deny: ["service.internal.>"]
                }
                subscribe: {
                    allow: ["service.>", "config.>"]
                    deny: ["service.internal.>"]
                }
            }
        }
    ]
}

tls {
    cert_file: "/etc/nats/tls/server.crt"
    key_file: "/etc/nats/tls/server.key"
    ca_file: "/etc/nats/tls/ca.crt"
    verify: true
    cipher_suites: [
        "TLS_AES_256_GCM_SHA384",
        "TLS_CHACHA20_POLY1305_SHA256"
    ]
}

7.6 本章總結

  • NATS 支援多種認證：密碼、Token、NKey、JWT
  • 主題級授權精細控制發布/訂閱權限
  • TLS/mTLS 確保傳輸加密
  • Accounts 實現多租戶隔離
