第 6 章：叢集與超級叢集 —— 全球神經網路

6.1 NATS 叢集架構

6.1.1 單一叢集（Cluster）

多個 NATS Server 組成叢集，共享訊息路由：

// Server 1 設定
server {
    listen: 0.0.0.0:4222
    server_name: n1
    cluster {
        listen: 0.0.0.0:6222
        routes: [
            "nats-route://n2:6222"
            "nats-route://n3:6222"
        ]
    }
}

6.1.2 叢集路由原理

當訊息發布到某個 Server 時，它會透過 Route 連線將訊息轉發給其他 Server：

Client A → Server 1 ──Route──→ Server 2 → Client B
              │
              └──Route──→ Server 3 → Client C

6.2 超級叢集（Super Cluster）

6.2.1 閘道（Gateway）連線

超級叢集透過 Gateway 連線不同地區的叢集：

// 東京叢集
cluster {
    name: "tokyo"
    listen: 0.0.0.0:6222
}

gateway {
    name: "tokyo"
    listen: 0.0.0.0:7222
    gateways: [
        {name: "london", urls: ["nats://london-gw:7222"]},
        {name: "newyork", urls: ["nats://ny-gw:7222"]}
    ]
}

【漫畫：全球叢集像神經網路】

東京、倫敦、紐約三個大腦區域，透過 Gateway 神經纖維連接，訊息在毫秒級傳遞。

6.3 原始碼解析：Route 連線

6.3.1 Route 結構

// server/route.go
type route struct {
    remoteID    string
    poolIdx     int
    didSolicit  bool
    gatewayName string
    accName     string
}

// Server 結構中的路由相關欄位
type Server struct {
    routes              map[string][]*client
    routesPoolSize      int
    accRoutes           map[string]map[string]*client
    routeListener       net.Listener
}

6.3.2 訊息轉發邏輯

// server/client.go - processMsgResults
func (c *client) processMsgResults(...) {
    // ... 本地訂閱處理 ...
    
    // 轉發給遠端路由
    if c.srv != nil {
        c.srv.routeMsg(subject, msg)
    }
}

// 路由訊息到叢集中的其他 Server
func (s *Server) routeMsg(subject string, msg []byte) {
    for _, route := range s.routes {
        route.sendMsg(subject, msg)
    }
}

6.4 Leaf Node——邊緣連線

Leaf Node 讓邊緣裝置安全地連接到中心叢集：

// 邊緣 Server 設定
leafnodes {
    remotes: [
        {
            url: "nats-leaf://central:7422"
            credentials: "/etc/nats/leaf.creds"
        }
    ]
}

6.5 實戰：全球訂單系統

// 東京發布訂單
tokyoNC.Publish("orders.global", []byte("新訂單 from 東京"))

// 倫敦和紐約自動收到
londonNC.Subscribe("orders.global", func(msg *nats.Msg) {
    fmt.Println("倫敦收到:", string(msg.Data))
})

nyNC.Subscribe("orders.global", func(msg *nats.Msg) {
    fmt.Println("紐約收到:", string(msg.Data))
})

6.6 本章總結

  • Cluster：多 Server 組成本地叢集，自動路由訊息
  • Super Cluster：透過 Gateway 連線多地區叢集
  • Leaf Node：邊緣裝置安全連接中心叢集
  • 訊息自動轉發，無需應用層處理
