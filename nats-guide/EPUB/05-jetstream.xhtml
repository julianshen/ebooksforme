5.1 什麼是 JetStream？

JetStream 是 NATS 的持久化層，提供：

  • 訊息持久化：將訊息儲存到磁碟，Server 重啟不丟失
  • 串流（Stream）：有序的訊息日誌，類似 Kafka 的 Topic
  • 消費者（Consumer）：獨立的消費進度追蹤
  • 至少一次交付：確保訊息不丟失
  • 訊息重播：可以從頭重新讀取歷史訊息

5.2 Stream 與 Consumer

5.2.1 Stream——訊息日誌

// 建立 Stream
js, _ := nc.JetStream()

stream, _ := js.AddStream(&nats.StreamConfig{
    Name:     "ORDERS",
    Subjects: []string{"orders.*"},
    Storage:  nats.FileStorage,    // 檔案儲存（持久化）
    Retention: nats.WorkQueuePolicy, // 工作佇列模式
    MaxMsgs:  100000,              // 最多保留 10 萬則
    MaxAge:   7 * 24 * time.Hour, // 最多保留 7 天
})

// 發布訊息到 Stream
js.Publish("orders.created", []byte("訂單 #12345"))

5.2.2 Consumer——消費進度

// 建立 Consumer
sub, _ := js.PullSubscribe("orders.*", "order-processor", 
    nats.Durable("processor-1"),  // 持久化消費者
    nats.AckExplicit(),           // 手動確認
)

// 拉取訊息
msgs, _ := sub.Fetch(10)
for _, msg := range msgs {
    // 處理訊息
    processOrder(msg.Data)
    
    // 確認已處理
    msg.Ack()
}

5.5 實戰：訂單處理系統

package main

import (
    "fmt"
    "time"
    "github.com/nats-io/nats.go"
)

func main() {
    nc, _ := nats.Connect("nats://localhost:4222")
    js, _ := nc.JetStream()

    // 建立訂單 Stream
    js.AddStream(&nats.StreamConfig{
        Name:     "ORDERS",
        Subjects: []string{"orders.*"},
        Storage:  nats.FileStorage,
        Replicas: 3,  // 三副本
    })

    // 發布訂單
    for i := 1; i <= 100; i++ {
        js.Publish("orders.created", []byte(fmt.Sprintf("訂單 #%d", i)))
    }

    // 建立持久化消費者
    sub, _ := js.PullSubscribe("orders.created", "processor",
        nats.Durable("order-proc-1"),
        nats.AckWait(30*time.Second),
    )

    // 處理訊息
    for {
        msgs, _ := sub.Fetch(10)
        for _, msg := range msgs {
            fmt.Printf("處理: %s\n", msg.Data)
            msg.Ack()
        }
    }
}

5.6 本章總結

  • JetStream 是 NATS 的持久化層，提供訊息儲存與重播
  • Stream 是訊息日誌，Consumer 追蹤消費進度
  • 支援 Memory 與 File 兩種儲存模式
  • 三副本複寫確保高可用性
