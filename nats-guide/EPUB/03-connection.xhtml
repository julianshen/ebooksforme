3.1 NATS 連線架構

NATS 使用持久 TCP 連線，Client 連接一次後維持該連線進行發布和訂閱。Server 處理所有路由邏輯。

3.1.1 連線生命週期

┌─────────┐     CONNECT      ┌─────────┐
│ Client  │ ───────────────→ │ Server  │
│         │ ←─────────────── │         │
└─────────┘     INFO         └─────────┘
       ↓                           ↓
┌─────────┐     SUB/PUB/UNSUB   ┌─────────┐
│ Client  │ ←────────────────→  │ Server  │
│         │     MSG/PING/PONG   │         │
└─────────┘                     └─────────┘
       ↓                           ↓
┌─────────┐     -ERR/QUIT      ┌─────────┐
│ Client  │ ───────────────→  │ Server  │
└─────────┘                   └─────────┘

3.1.2 連線協議

NATS 協議是基於文字的，極其簡單：

// Client 發送
CONNECT {"verbose":false,"pedantic":false,"tls_required":false}
SUB orders.created 1
PUB orders.created 5
Hello

// Server 回應
MSG orders.created 1 5
Hello

3.2 自動重連機制

NATS Go Client 內建強大的重連機制：

nc, err := nats.Connect("nats://localhost:4222",
    nats.MaxReconnects(10),           // 最多重連 10 次
    nats.ReconnectWait(time.Second),  // 每次間隔 1 秒
    nats.ReconnectHandler(func(nc *nats.Conn) {
        log.Println("重新連線成功！")
    }),
    nats.DisconnectHandler(func(nc *nats.Conn) {
        log.Println("連線中斷...")
    }),
    nats.ClosedHandler(func(nc *nats.Conn) {
        log.Println("連線已關閉")
    }),
)

3.3 原始碼解析：Client 結構

3.3.1 client 結構體

// server/client.go
type client struct {
    kind  int           // CLIENT, ROUTER, GATEWAY, LEAF
    srv   *Server       // 所屬 Server
    acc   *Account      // 所屬帳戶
    nc    net.Conn      // TCP 連線
    subs  map[string]*subscription  // 訂閱映射
    
    // 連線狀態
    cid        uint64    // 唯一 Client ID
    start      time.Time // 連線開始時間
    last       time.Time // 最後活動時間
    
    // 緩衝區
    in     readCache    // 讀取緩衝
    out    outbound     // 發送緩衝
}

3.3.2 readLoop——訊息讀取核心

// server/client.go
func (c *client) readLoop(pre []byte) {
    c.mu.Lock()
    s := c.srv
    nc := c.nc
    c.in.rsz = startBufSize
    c.mu.Unlock()

    // 啟動讀取緩衝
    b := make([]byte, c.in.rsz)

    for {
        // 讀取資料
        n, err := nc.Read(b)
        if err != nil {
            // 處理斷線...
            return
        }

        // 解析協議
        if err := c.parse(b[:n]); err != nil {
            // 處理解析錯誤...
            return
        }
    }
}

3.4 連線池與緩衝區管理

3.4.1 讀取緩衝區動態調整

// server/client.go - readLoop 中的緩衝區調整
if n == len(b) && c.in.rsz < maxBufSize {
    // 緩衝區滿了，擴容
    c.in.rsz *= 2
    b = make([]byte, c.in.rsz)
}

3.4.2 發送緩衝區

type outbound struct {
    pb   int64       // pending bytes
    pm   int32       // pending messages
    sg   sync.WaitGroup
    nb   net.Buffers // 待發送緩衝
    fsp  int         // flush signal pending
}

3.5 實戰：連線最佳實踐

// 生產環境連線設定
nc, err := nats.Connect(
    "nats://n1:4222,nats://n2:4222,nats://n3:4222", // 多 Server
    nats.Name("order-service"),                        // 識別名稱
    nats.Timeout(2*time.Second),                       // 連線超時
    nats.PingInterval(20*time.Second),                 // 心跳間隔
    nats.MaxPingsOutstanding(2),                       // 最大未回應心跳
    nats.ReconnectBufSize(10*1024*1024),              // 重連緩衝 10MB
    nats.RetryOnFailedConnect(true),                   // 連線失敗時重試
    nats.DrainTimeout(10*time.Second),                 // 優雅關閉超時
)

3.6 本章總結

  • NATS 使用持久 TCP 連線，協議極簡（文字協議）
  • Client 內建自動重連機制，可配置重連策略
  • 每個連線有獨立的 readLoop goroutine，無鎖競爭
  • 讀寫緩衝區動態調整，適應不同負載
