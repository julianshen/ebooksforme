8.1 HTTP 監控端點

NATS Server 提供內建 HTTP 監控端點：

// 啟動監控
nats-server -m 8222

// 或設定檔
http_port: 8222

// 查詢端點
curl http://localhost:8222/varz      // Server 資訊
curl http://localhost:8222/connz     // 連線資訊
curl http://localhost:8222/routez    // 路由資訊
curl http://localhost:8222/subsz     // 訂閱資訊
curl http://localhost:8222/jsz       // JetStream 資訊

8.4 日誌與追蹤

8.4.1 啟動追蹤

// 追蹤所有協議訊息
nats-server -V

// 或設定檔
trace: true
debug: true

// 輸出範例
[TRC] 10.0.0.1:54321 - cid:1 - ->> [SUB orders.created 1]
[TRC] 10.0.0.1:54321 - cid:1 - ->> [PUB orders.created 11]
[TRC] 10.0.0.1:54321 - cid:1 - <<- [MSG orders.created 1 11]

8.5 Prometheus 與 Grafana

// 使用 prometheus-nats-exporter
prometheus-nats-exporter \
    -varz \
    -connz \
    -routez \
    -subsz \
    -jsz \
    http://localhost:8222

// 或啟用內建 Prometheus 端點（NATS 2.10+）
http_port: 8222
prometheus_port: 7777

8.6 分散式追蹤

// 使用 NATS Msg Header 傳遞追蹤 ID
msg := nats.NewMsg("orders.created")
msg.Header.Set("X-Trace-ID", generateTraceID())
msg.Header.Set("X-Span-ID", generateSpanID())
msg.Data = []byte("訂單資料")

nc.PublishMsg(msg)

// 訂閱者繼續傳遞追蹤資訊
nc.Subscribe("orders.created", func(msg *nats.Msg) {
    traceID := msg.Header.Get("X-Trace-ID")
    spanID := msg.Header.Get("X-Span-ID")
    
    // 記錄到 OpenTelemetry/Jaeger
    tracer.StartSpan("process-order",
        opentracing.ChildOf(spanContext),
    )
})

8.7 本章總結

  • NATS 提供內建 HTTP 監控端點（/varz, /connz, /routez 等）
  • 支援協議級追蹤（-V 參數）
  • 可整合 Prometheus + Grafana
  • 使用 Msg Header 實現分散式追蹤
