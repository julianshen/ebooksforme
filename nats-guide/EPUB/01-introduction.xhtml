1.1 什麼是 NATS？

NATS（Neural Autonomic Transport System）是一個開源、雲原生、高性能的訊息系統。它由 Derek Collison 於 2010 年創建，現為 CNCF 孵化專案。

與傳統訊息佇列（如 RabbitMQ、Kafka）不同，NATS 的設計哲學是：

  • 簡單至上：協議極簡，只有 PUB、SUB、UNSUB、MSG 四種核心指令
  • 性能優先：單機每秒可處理數百萬則訊息
  • 彈性擴展：自動發現、自動路由、無縫擴展
  • 無處不在：從雲端到邊緣，從容器到嵌入式裝置

1.2 NATS 的核心特性

1.2.1 發布/訂閱（Pub/Sub）

最基本的模式：發布者發送訊息到「主題」（Subject），所有訂閱該主題的接收者都會收到。

// 發布者
nc.Publish("orders.created", []byte("新訂單: #12345"))

// 訂閱者
nc.Subscribe("orders.created", func(msg *nats.Msg) {
    fmt.Printf("收到訂單: %s\n", msg.Data)
})

1.2.2 請求/回覆（Request/Reply）

建立在 Pub/Sub 之上的同步通訊模式，類似 HTTP 但更高效。

// 請求方
resp, err := nc.Request("orders.validate", []byte("#12345"), 2*time.Second)

// 處理方
nc.Subscribe("orders.validate", func(msg *nats.Msg) {
    // 驗證訂單...
    msg.Respond([]byte("驗證通過"))
})

1.2.3 佇列群組（Queue Groups）

多個消費者組成群組，訊息只會被群組中的一個成員處理，實現負載均衡。

// 三個消費者組成 "workers" 群組
nc.QueueSubscribe("orders.process", "workers", handler)

1.3 NATS vs 其他訊息系統

特性NATSKafkaRabbitMQ
協議複雜度極簡（文字協議）複雜（二進制協議）中等（AMQP）
吞吐量數百萬/秒數十萬/秒數萬/秒
延遲微秒級毫秒級毫秒級
持久化JetStream（可選）預設持久化可選持久化

1.4 快速開始

1.4.1 安裝 NATS Server

# Docker
docker run -p 4222:4222 nats:latest

# 或下載 binary
wget https://github.com/nats-io/nats-server/releases/latest/download/nats-server-amd64
chmod +x nats-server-amd64
./nats-server-amd64

1.4.2 第一個 Go 程式

package main

import (
    "fmt"
    "github.com/nats-io/nats.go"
)

func main() {
    // 連接到 NATS Server
    nc, err := nats.Connect(nats.DefaultURL)
    if err != nil {
        panic(err)
    }
    defer nc.Close()

    // 訂閱主題
    nc.Subscribe("hello.world", func(msg *nats.Msg) {
        fmt.Printf("收到: %s\n", msg.Data)
    })

    // 發布訊息
    nc.Publish("hello.world", []byte("哈囉，NATS！"))
    
    // 等待訊息處理
    nc.Flush()
}

1.5 本章總結

  • NATS 是雲原生時代的高性能訊息系統
  • 核心模式：Pub/Sub、Request/Reply、Queue Groups
  • 極簡設計，單機可處理數百萬訊息/秒
  • 與 Kafka/RabbitMQ 相比，更輕量、更低延遲
